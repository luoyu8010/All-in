# All In 1.2.50-test（56）本地候选

基于 55 版完成 Antigravity 接入兼容与拒绝诊断修补；尚未公开发行。原有账号无需卸载或清除数据。

## 接入更新

参考社区 `@magpie-community/opencode-antigravity-auth` 0.2.1，源码提交 `34e32a1f443e656d255b1cc23363436559accacd`，核心发布文件 SHA256 `10cd2ca45fa194a4270d189ec958aa27e961abe4f0d086d4af66a40435a0d4d9`。

- 新授权请求增加 `aicode`，保留原 PKCE、state 与本地回调校验。Google 返回 scope 时保存其返回值；缺少记录的旧账号不被武断判断为缺权或强制移除。普通 token 刷新不被当作新增授权。
- 请求头使用已核对的 2.32.1／构建号 1021296516 格式，平台和架构取本机实际值。修正传入的 User-Agent 未用于实际发送的问题，去掉旧的显式 SSE Accept。
- `onboardUser` 采用 `tierId`、`metadata.ideType`，按服务端 allowedTiers 的默认项选择，缺省回退 free-tier。项目分配和相关档位信息仍经过既有事务发布，不改变账号身份或其他供应商。
- 生成请求携带会话轨迹、步骤、模型提供方标签及新的 requestId；模型目录保存各具体变体的枚举，按实际选中的变体生成 model_enum。旧缓存缺枚举时省略，不编造。
- Antigravity 请求独立保留上游字段序列化顺序，不改变共享 JSON 库或其他供应商的序列化行为。

## 拒绝诊断

保留上游 HTTP 状态，并从完整错误中提取有界 message／status／ErrorInfo.reason。只向面板提供允许字段，不透传任意 metadata；对凭据回显脱敏。明确的 scope 不足、地区／服务资格拒绝与原因未明的 403 分别说明，不把所有 403 当作 token 过期。页面兼容旧响应，优先展示安全的结构化详情，并保持 HTML 转义。

## 保留的边界

保留账号、事务/CAS、取消、未知执行不重放与 403 不生成重试的规则。不引入自动消费 Google AI credits、生成后自动重试或新的渠道识别绕过提示词策略。版本／构建号固定为此次已核对的成对常量，未引入插件的运行时版本清单联网自更新、完整搜索钩子或其他宿主功能。

上游 0.2.1 README 已声明不再向新用户提供此直连插件。本次修补不承诺 Google 后续允许所有第三方调用，也不把本地测试通过当作客户账号 403 已解决。

## 验证

实际结果由本地交付目录的 TEST_RESULTS.json／REPORT.md 记录。当前已完成 18 项相关 JVM/HTTP 执行任务、47 项面板回归、Android API34 隔离运行时 226 项（其中新接入检查 22 项），均通过；Release Lint 已完成。全部供应商请求夹具为合成数据，未操作真实账号或进行真实 Google 推理。签名、覆盖升级和最终打包结果以交付记录为准。
