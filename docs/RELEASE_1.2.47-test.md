# All In 1.2.47 正式版（内部1.2.47-test / 53）

本版先在专用 Android 14 模拟器复现 52 版审查报告问题，再修补和验证。保留已验收原证书安装包，内部版本名仍为1.2.47-test（53）；CI仍仅手动。

## 修复

- SSE 单行、单事件和同时活动的分帧内存有明确上限；合法的小帧长流仍增量传输，不设置整个长流总量上限。标准多行 data、LF/CRLF、注释和 EOF 分帧可用。
- 普通流账本等最终交付结果，错误和取消不记成功；已经确认的用量保留且记录一次。Responses 转换会验证上游结束并传递最终交付通知。
- Qoder 登录只记录受控 HTTP/阶段信息，不记录原始授权正文、凭据或未清洗异常。
- 生产连接对端保持真实 IPv4/IPv6 字节及 Socket 收发/关闭，只用数字显示名称，避免鉴权和 HTTP 头保护前的 PTR 等待。原始Socket外连 DNS 使用四个无队列槽，纳入连接总期限；阻塞解析不触发无限线程替换。
- 模型候选统一由供应商 ID 和上游原始 ID 构造完整引用；原始 ID 自带同名前缀时不再错误删一层。
- 签到在持久围栏之后、交给传输之前核对启用、身份、凭据和账号代际。发送提交之后的远端操作不能承诺撤销，原同日防重放围栏仍保留。
- ZCode 校正只选启用的静态 API 凭据，遵守对象 Key/停用镜像过滤；供应商、凭据或网络快照变化后不回写旧端点结果。
- 账本常驻明细最多 2048 条/估算 4MiB，失败待写最多 512 条/估算 1MiB；恢复确认写入后排空，不重复统计。月+序号文件真的分片。完整历史汇总改为磁盘流式归约，不常驻全部 Row。

## 存储与验收边界

不自动删除用户历史账本。磁盘不可写且失败缓冲超限时，部分明细会被丢弃；有界时段汇总、丢弃/缺失计数和完整性诊断明确保留，恢复后写入私有 ledger-gaps.json。超出汇总容量或无法覆盖精确时间边界时，不能把数据假称完整。CSV 当前有界导出最近 1000 条并明确写出范围/缺失说明，完整历史汇总仍可查询；并非把截断导出说成全量账本。

旧版复现和新版对照使用实际 Release APK 的 Android ART 隔离进程、实际 Android WebView 及合成故障/凭据，不使用真实领取、付费推理或强制刷新。超长流的 Android 实际最大堆为 192MiB，不冒称命令中的 48MiB 生效；新 JVM 边界回归实际在 48MiB 下通过。

最终本地 257 个 JavaExec 执行任务通过（不是 257 个独立业务场景），面板 46/46、Android 运行时 83/83；新边界回归 62 检查，模型前缀回归 17 检查。另有 10 项 Release/WebView 旧版与新版明确输出对照。Lint 和签名结果见交付记录。

专用模拟器原数据 52→53 覆盖升级，账号、私有配置、管理身份和 UID 保留，安装 APK 与交付字节一致。故障验证未使用真实领取、付费推理或强制刷新；运行时和 WebView 验证使用隔离环境。安装时请勿卸载或清除数据。

R1 息屏无线策略、旧 API/OEM、全部真实供应商/账号/模型、长期运行未全面覆盖；不将本次模拟故障对照写成用户实际网络故障唯一根因。本地验收时未推送或发版；随后由维护者另行授权完整入库并正式发行。没有恢复自动CI、更新固定上游或进行额外真实账号业务请求。
