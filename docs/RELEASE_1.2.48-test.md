# All In 1.2.48 正式版（内部1.2.48-test / 54）

本版在完成本地复核、修补和验收后，经维护者明确授权正式发行。为保留已验收安装包原字节，内部版本名仍为1.2.48-test（54）。CI仍仅手动，最低Android版本与依赖不变。

## 本轮修补

- Codex HTTP OAuth 回调仅接受本机 GET；动态 HTML 文本转义，禁止脚本执行并禁止缓存/来源泄露。公开 OAuth 回调并不是绕过 state 的登录入口。
- Codex / Antigravity 手动授权严格匹配有效流程。flowId 与 URL state 同时存在时必须一致，不再随意取第一个流程；成功后清理实际匹配的流程，错误输入不改其它流程。
- Antigravity 连通性诊断只接受本项目使用的明确业务域名，不接受任意主机/IP。
- Codex 原生响应明确绑定请求生命周期，取消、异常、重试交接与结束均释放连接；原生 JSON/compact 不再错误标为 SSE。Codex/Copilot 原生路径新增单条终态用量记录；Codex 原始直通不猜测 token，用量未知仍是未知。
- Copilot 原生流在释放时注销连接，非流式读取真实 usage；原生 Responses 记账等待最后的响应写入/flush，不因读到完成事件提前报成功。客户端取消、写失败与上游错误不当成功，已有数字用量不丢失。
- Raccoon 已发送一轮、续期后再次准入被拒，不再把整次调用标为本地拒绝。中文“超出配额/额度”不再被宽泛的“超出”判成上下文超长；真实输入/上下文过长和未知执行不重放规则保持。
- Copilot 切换 Responses 接口前先关闭已完整读取的旧 4xx 连接。WorkBuddy 非流式估算 usage 与客户端/账本保持一致，并明确标为 estimated。
- SSE 内存预算改为分块预留，仍在分配前检查全局预算，行/事件上限、立即拒绝、EOF/异常/混用与重复 close 的释放规则保留；不引入整条长流缓存或总长度上限。
- 四处真正的单次资源读取改为循环读取并确保关闭；普通文件读取异常也确保关闭。图标原有响应流发送不误作单次 read 删除。
- 清除 GatewayServer 的 19 处 printStackTrace；日志仅受控阶段与异常类名，不输出异常正文、堆栈、cause 或 suppressed 内容。ZCode 校正无可达端点/保存失败与回调监听启动失败有有限诊断。
- 请求线程的 Origin / 用量等上下文在入口和退出清理；watchdog 读取一致快照，状态文件使用 fsync + 原子替换。删除接口仍幂等，通用路径增加 removed:false 区分不存在；usage 端点精确匹配，四处配置状态令牌统一恒时比较。
- 修正 ZCode 登录站点把 Boolean 与字符串比较、总选 Z.ai 的错误，并防御空 base；Trae 冷却空正文不抛异常。Antigravity 转发异常经过现有凭据清洗。
- 删除账本未使用的 future/addFuture/MAX_FILE_BYTES，保留实际时间索引、缺失明细统计、分片、回滚及 uncertainWrites。

## 明确的边界与未采纳建议

- DNS 四槽仅覆盖原始 Socket 的 connectTunnel。HttpURLConnection/openHttp 不受该四槽 DNS 期限保护。平台解析器不响应中断时不能仅靠 Java deadline 强制退出；保持四槽、无队列、拒绝饱和，不无限新建线程。`GET /api/status` 管理接口的 `connections.outboundDns` 报告活动槽、饱和、超时/拒绝计数。恢复测试是平台解析器返回后恢复，不冒称强制回收卡死系统调用。
- 原版在本机 JVM 的回环 TCP 试验中，关闭响应流已经能让对端观察到断开；因此“所有客户端取消都不断连、必然继续扣费”未获证实。确有的是原生路径缺少显式释放/请求取消接线与账本，现按上述范围修补；没有真实计费试验。
- Antigravity 的失败保留已交换一次性凭据是已有明确恢复契约；未机械改深拷贝，避免丢掉已消费登录凭据。此例外不等于所有配置保存失败都承诺内存原样不变。
- Qoder/Trae 指定失败分支本已产生有效 HTTP 错误码，通用内部 status=0 也映射到 502；未复现报告所说的两个 500 现场。Loomy 的候选来自本机新建的全 JSONObject 数组，所述 null 元素前提不成立。
- DeepSeek 临时移除再恢复 Row 是父转发 finally 仍要归因的设计；保留恢复，统一在最外层请求结束清理。CatPaw open 内已经可能发送/收到上游响应，不能把 markSent 简单后移到 open 返回后；保留保守发送边界。
