# All In 1.2.49 正式版（内部1.2.49-test / 55）

基于54版源码完成账户识别、移除和列表刷新修补，经维护者明确授权正式发行。为保留已验收的原签名安装包，内部版本名仍为1.2.49-test（55），没有为发版重新构建或更换证书。CI仍仅手动。

## 账户识别

- 管理弹窗优先显示本地备注、邮箱、已有名称或登录名，不再显示“账号 •••• #1/#2”。手机号保留中间遮罩；缺少身份资料时显示稳定的本地标识并提示设置备注，不拿凭据当名称。
- 增加每个账号的备注编辑；备注是展示字段，不修改登录身份、顺序、凭据、启停状态或签到记录。JSON迁移保留备注。
- 单账号快捷移除与多账号列表统一确认，确认框及回执明确标明目标账号；取消不发送移除请求。名称作为纯文本渲染，长邮箱换行而不是裁掉关键信息。

## 真正删除与列表刷新

- 修正通用、MiniMax、Trae的`id=all`清空处理；统一单删、全清、重复删除的实际移除计数。保存失败不发布新账号池；缺失账号不伪称产生新的移除。
- 删除账号同步清理属于该账号的镜像Key，保留独立手动配置的Key和其他供应商。刷新凭据时同步更新镜像，避免旧访问凭据在删除后遗留。
- 必须有完整账号的内置协议不再将历史遗留的孤立Key算作“已接入”；不会猜测并删除无法证明归属的旧数据。支持独立API Key的供应商，在仍有独立Key时继续显示。
- 清空后无账号/可独立使用Key的供应商退出已接入列表，仍可在“添加供应商”重新接入。停用但仍保存的账号不会被误藏。
- 删除/备注操作采用供应商状态校验和配置读回保护；轮询复用操作后的读回，避免抢占刷新。旧读取不能恢复已删除账号，备注输入中的草稿不会被周期刷新覆盖。
