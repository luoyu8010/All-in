# All In 1.2.66 正式版

- 重构首页、接入、供应商、路由、治理和隐私界面，统一浅色与深色主题下的卡片、控件和底部导航。
- 底部 Dock 支持点按滑动、拖动跟手和松手回弹，页面随切换方向过渡。路由及隐私开关加入可跟手拖动的滑块和落位动画。
- 供应商列表与添加目录双向滑动，供应商详情、签到中心和高级设置增加进入与返回过渡。账号管理抽屉和设置折叠区域也加入开合动画。
- 单选下拉和账号操作菜单从触发控件展开并收回，白天为白底，夜间为黑底。
- 网关状态切换增加按钮反馈与波纹，手动刷新增加图标转动和亮边反馈。用量日期滑块与柱状图随时间范围平滑切换。
- 首次设置使用 All In 应用图标。三个步骤支持双向滑动淡入和内容高度过渡。完成设置后，引导页淡出，首页顶栏、首张卡片和底部 Dock 依次显现。
