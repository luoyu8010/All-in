# All In 1.2.53 正式版（59）

新增供应商独立的账号路由设置：轮流使用、用量均衡、到期优先。账号与 API Key 均可设置；模型权限、停用、冷却、发送预算及未知执行保护仍先于路由偏好。

用量均衡在完整、新鲜的额度快照间比较使用比例，比例接近的账号按本机近期可信 Token 和在途负载分配；资料不全时统一回退本机负载。到期优先按明确将作废的额度占比除以剩余小时排序，小时下限1；没有可靠信息时回退均衡。不会将 Token、积分、金额相加，也不承诺各账号的积分消耗严格相同。

WorkBuddy 参考本地 npm 0.2.34，补齐只读的付费/免费积分包分页、UTC+8日期、实际奖励积分到期数量、额外奖励去重与个人/团队周期。MiniMax 保留原积分明细的到期数量；其他已接入的额度窗口和周期统一参与排序。没有提供可靠到期信息的供应商显示回退依据。

新鲜度120秒，使用中的候选账号每60秒最多发起一次额度读取，最多2个工作线程及16个排队任务；读取失败维持未知。不会为均衡调用推理、签到、领取或付费套餐接口；Raccoon 不自动调用可能领取赠送的余额回退。

策略持久化，默认仍轮流；近期Token负载和在途预约仅内存态、重启清空。入口为供应商详情中的“账号路由”，选择后立即保存。

发布级别为正式版，APK内部仍保留已验收的版本名1.2.53-test和versionCode59；使用原证书、原安装包字节，不重建或重签。已安装59候选包的用户无需为本次正式发行重复安装。

验证范围：面板48/48、隔离Android API34运行时563项通过，四Key真实回环HTTP的20次等用量请求分配为5/5/5/5。相关28个JVM/HTTP执行任务27过，仍有一项上一版已记录的ZCode取消断言差异（实际499/1，旧期望502），未删断言或宣称全量全绿。真实供应商账号的长期积分消耗、到期扣除、全部模型与OEM设备尚未全面覆盖。

请直接覆盖安装，勿卸载或清除账号数据。APK、精确Git源码包、update.json与SHA256SUMS位于[正式发布页](https://github.com/xunianooo/All-in/releases/tag/v1.2.53-test)。
