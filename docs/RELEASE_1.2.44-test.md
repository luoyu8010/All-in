# All In 1.2.44 正式版（50）

## 本版更新

- 新增首页检查更新卡片、浅深色更新弹窗、暂不更新与立即更新；每9小时安排检查，支持前台补查和手动即时检查。
- 整合配置并发事务、账号级代际和完整配置 revision 保护，避免无关设置覆盖续期结果或旧快照覆盖新账号。
- 修复对象格式独立 Key 的路由识别，保留停用、去重、账号镜像和赠送/付费隔离。
- 加强面板重复流式提交、离页取消及异步迟到启动保护；补齐普通响应大小、期限、HTTP分帧及 gzip 完整性校验，长流仍增量读取。

## 安装与更新

这是正式发布，非预发布。APK内部版本名和标签仍为 **1.2.44-test**，versionCode **50**，以保留已验收原签名包不变。使用原证书，可覆盖安装旧版本；请勿先卸载或清除应用数据。

发布附件包括原签名APK、与提交精确一致的完整源码ZIP、update.json及SHA256SUMS.txt。update.json对应本标签与versionCode 50；未来新版本必须提高versionCode，不得把它挂到其他版本。

更新检查只读取固定公开GitHub正式Latest，不发送账号、管理凭据、API密钥或Cookie。存在有效update.json时优先比较versionCode，兼容此前数字标签。草稿、预发布、无效元数据、网络/限流或存储失败不冒充已是最新。立即更新只打开官方最新发行页，不自动下载或安装。

后台任务按上次成功检查加9小时安排，手动成功也对齐下次截止。系统省电、网络、强制停止或关机可能延后；打开App补查。暂不更新对同一发行版9小时不重复自动提醒，手动仍可提示，新发行版不被旧忽略记录屏蔽。
