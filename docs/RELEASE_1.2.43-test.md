- gzip流解压结束后仍检查HTTP分帧完整性：固定长度不足、缺少终止chunk、截断trailer拒绝，不把压缩成员结束当作HTTP结束。继续逐段输出，不整包缓存、不限制整个SSE大小或修改模型输出参数。
