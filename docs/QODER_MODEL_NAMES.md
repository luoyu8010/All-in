# Qoder 对外模型名称

Qoder 的官方目录分别提供稳定路由 key 和展示名称，例如 `gmodel` 与 `GLM-5.3`。供应商页和客户端模型列表应显示相同的官方名称。

`GET /v1/models` 对 Qoder 返回 `qoder_cn/<官方名称>`，同时提供 `name` 和 `display_name`。接入页可复制的模型 ID 使用同一映射。名称按已同步目录中的 `display_name`、`displayName`、`name` 顺序读取，不写死型号；没有有效名称时保留原 key。

客户端直接使用列表中的完整 ID 即可。网关在选择账号前把它还原为原 key；账号目录、上游 `model_config.key`、签名模型头、权限、冷却和用量归因继续使用原身份。旧的 `qoder_cn/gmodel` 等配置仍可调用，原路由组和白名单保留。白名单保存时使用原身份，官方改名不会把已选模型丢掉。

同一目录有多个同名模型时，公开 ID 附加原 key，例如 `qoder_cn/Qwen3.8-Max (qmodel_38max)`，确保客户端可以分别选择。原 key 优先于另一个模型恰好相同的展示名称；冲突或无效名称不会被合并为另一个模型。

列表读取只使用已保存目录，不同步令牌、不查询真实上游、不发起推理。官方目录更新名称后，重新同步官方模型，并让客户端重新拉取模型列表。旧原始 key 继续兼容；旧展示名称不是永久别名。

本说明对应源码修补，不表示既有发布 APK 已包含修补。
